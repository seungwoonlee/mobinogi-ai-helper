## 2. 중간 지적 반영

- 가드 적용 범위를 `tests/__init__.py`로 확대, 원인 체인(`__context__`) 제거 → §4.1
- 카나리 변형 확대(JSON 이스케이프·UTF-16·cp949·퍼센트, 부분 조각 6자), 모의 CLI 로그 분리, Base64 한계 명시 → §5-3
- 확인 불가 문구에서 사실 단정 제거("전송됐을 수 있지만") → §4.7
- 표본 확보 도구: 채팅창 확인 문답, 거부 표본 방법, 어댑터 직접 사용 예외 → §4.9

- 대화 모드는 표준 입력이 터미널일 때만 `TYPED`, y 확인 한 글자 한정, 입력 버퍼 비우기, tty 상속 한계 → §4.4
- `config_verified` 명칭 정리 → §4.2·§4.3
