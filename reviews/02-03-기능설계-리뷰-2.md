## 2. 중간 중요도 조치 요약

- 자동 행동과 `@@` 예외의 모순 → 03 §5.3(미리보기 전체 확정으로 승인)
- 승인 유효 시간: 실행 직전 재검증, 단조 시계, 만료 뒤 재열기 → 03 §5.2
- 다회 호출 승인과 총비용, 이중 소모 경고 → 03 §3, §4, §5.2
- 대기 슬롯과 초안 일원화, 초안 만료 재확인, 창 숨김 알림 → 03 §6.5
- 행동만 재전송 경로 → 03 §6.4
- 재시작 복구 충돌 정리와 write-ahead 기록 → 03 §3, §4, 02 §5.3
- 저장 허용 목록, Base64 한계, 오류 원문 미표시, 진단 허용 목록 → 03 §3, §8
- 외부 AI로 나가는 정보 최소화, 게임 유래 텍스트의 비신뢰 처리 → 03 §8
- 입력 정규화(NFKC·비가시문자) → 03 §6.1
- 행동 판정 근거(허용 행동 목록), 메타데이터 가정 표시 → 03 §2, §12
- `SYSTEM` origin은 `QUERY` 전용 → 03 §5.4
- 02와 03 용어 대응, 게임 축 부가 값(`probe_paused_by_action`, `last_ok_at`) → 02 §4.4
- 구현 순서에 03 산출물 배정 → 02 §16
- 후보값·가정 표시 규칙 → 02 §3, 03 §1
