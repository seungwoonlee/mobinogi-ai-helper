## 2. 중간 지적 반영

- 판정 필드 우선순위·설정 파일 fail-closed·`verified` 의미 → §4.2, §4.3
- 저장 실패 시 전송 중단, 원자적 쓰기, 스키마 버전, `pending` 기준 → §4.6
- Ctrl+C·프로세스 트리·출력 상한·오류 주입 목록 확대 → §4.1, §5-1
- 원문 미기록 검증(카나리, 예외 표현, Base64 세 형태) → §5-3
- `origin` 부여 주체(인자 모드 거부), `AI_APPROVED` 승인 객체, 확인 값 분리 → §4.4
- 판정 사유 열거값(3단계 연결) → §2-5
- 어댑터 시그니처(타임아웃 None, 취소 이벤트, 출력 상한) → §4.1
- 모의 CLI 구동 방식(인터프리터 접두, 호출 로그) → §4.1, §2-9
- T번호 추적표, 퍼징 범위, 테스트 전용 설정 주입 → §5-2, §5-4, §5-5
- 표본 확보 절차 → §4.9
- 세대 번호 규칙 테스트 → §4.5-8
- 동시성 모델(`BUSY`)과 프로세스 간 제한 → §2-8, §4.6
