## 2. 승인 뒤 반영한 중간 지적

- `probe_paused_by_action` 해제를 게임 상태와 무관하게 정리(G25에 C34 포함)
- `PendingSlot` 정의를 C4·C4a에 통일(AI 조회는 슬롯을 쓰지 않음)
- 화해 시작 조건을 조건형으로 변경(C35)
- 슬롯 30분 만료를 독립 사건으로 분리(C7a), 세션 없음 응답 행 추가(C36)
- 시나리오 ID 범위와 단계별 적용 표 정정

## 3. 남은 중간·낮음 지적(구현 단계에서 처리)

- 03 §9.1 사용성 시험의 세부 프로토콜과 승인·초안 시간 후보값의 실측
- `ACTION` 응답 판정표(C18 "정상 완료" 기준)는 구현 4단계 설계에서 확정
- AI 요청 상태의 스트리밍 중 도구 호출 필요 여부는 AI 대화 설계(6단계)에서 결정
- 02 §15의 ID 미부여 필수 시나리오는 해당 단계 착수 전 ID 부여
- 화면 문구·승인 카드·상태별 표시는 `04-UI-상세설계.md`에서 처리
